# Intelligence-Augmentation-in-XR

This repository is for the talk "[Intelligence Augmentation via Ecopsychophysics in XR](https://youtu.be/vFJcmOWhZ-o)".

Presented at the Sandia XR Conference, July 21, 2026. Sandia National Labs.

The code in this repository contains simulations for 

[Directional Gradient via Just-noticable Differences](https://github.com/OREL-group/Intelligence-Augmentation-in-XR/blob/main/directional-gradient-just-noticable-differences.py).

* this code takes a matrix of Gaussian noise and orders it using a just-noticable differences criterion.

* the result is a directional gradient sorted by shade from light to dark.

[Prism Shift](prism-shift.py).

* this code simulates the effects of a prism illusion. The perceptual agent initially moves towards the distorted target, then makes a correction to the actual target.

[Virtual Prism Illusion](virtual-prism-illusion.py).

* this is a simulation of a perceptual agent adapting to a prism illusion.

* the code visualizes results of the simulation by movement to a target. Visualization can be done both in terms of behavior averaged across a population of agents and variation across a populaiton of agents.
